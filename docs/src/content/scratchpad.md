# Scratchpad

Notes that belong to no engagement, and to nobody but you.

The Notes tab on an engagement is the record of what was tried on *that* target: it belongs to the
job, it is visible to everybody on it, and it goes when the engagement goes. That is right, and it
is not where the rest of a tester's memory lives — the payload that worked, a client's odd SSO
behaviour worth remembering next year, a half-formed idea at four in the afternoon. That used to
live in a text file on somebody's own laptop, where it was neither searchable nor backed up nor
encrypted with everything else.

**Scratchpad** in the sidebar, below everything belonging to the firm.

## It is private, with no exceptions

There is no sharing switch and no administrator's view. A scratchpad somebody else might read is a
scratchpad nobody writes honestly in, and the server scopes every request to the account making it
rather than checking ownership afterwards.

The way a note becomes visible to anybody is to move it.

## Moving one onto an engagement

**Move to an engagement** offers every engagement you can open, and two ways to do it:

| | |
| --- | --- |
| **Copy** | It arrives on that engagement's Notes tab and your own copy stays here. The usual choice: the note is often a personal reference that stays useful after the part worth telling somebody has been written up. |
| **Move** | It arrives there and leaves the scratchpad. For the one that was only ever meant for that job. |

Either way it becomes an ordinary note: on the record, in the activity log, and if it mentions a
colleague they are told, exactly as if it had been typed there.

## Searching

The box searches titles, body text and tags across everything, in the browser — so it works on the
note you are halfway through writing, which a server-side search would not.
